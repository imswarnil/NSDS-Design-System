Hook — Mistake-first
"This one line of code will crash your org." — leads with a consequence, not a topic.
Hook — Contrarian
"Stop using Workflow Rules. Here's why." — challenges a common habit immediately.
Hook — Result-first
"I passed the Admin cert in 14 days doing this." — opens on outcome, not process.
Hook — Direct question
"Ever wonder why your flow runs twice?" — names the exact pain the viewer already has.
Closure — Recap + tease
"So: bulkify, cache, go async. Next lesson: testing all three." — one-line recap, named next step.
Closure — Single CTA
"If this helped, the full course is linked below." — one action, never subscribe+like+comment+follow stacked.
Closure — Community loop
"Which one did you not know? Tell me below." — used only on discussion/opinion content, not tutorials.
