About this course

Salesforce is a platform before it is a product, and Apex is how you extend it. This course starts where every other one should: the data model, the security model, and what actually happens when a record is saved.

Every lesson has the same shape — a plain-English concept, one concrete example you build yourself, and a bridge to the next step.

In short

If you can write an if statement and you have a browser, you can finish this. What you will not have at the end is a certificate you cannot defend — every lab runs in your own org, and the code is yours.

Terms you will own by lesson 10
Governor limit
The per-transaction ceiling the platform enforces — queries, rows, CPU time.
Bulkification
Writing for a list rather than a record, so 200 rows cost one query and not 200.
Selective query
A filter the platform can serve from an index rather than by reading every row.
