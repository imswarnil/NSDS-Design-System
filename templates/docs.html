Tokens

Every colour, size, radius and duration in this system is a token. A literal value in a component is a bug in exactly one theme, and nobody notices which.

Using them

Tokens are CSS custom properties on :root. Use the semantic name rather than the scale position: --color-ink rather than --color-brand-900, because the semantic one flips in dark mode and the scale one does not.

TipImport the tokens as JS too — import tokens from "nsds-design-system" — when a chart library needs the values rather than the variables.

They are generated, and it is enforced

tokens/*.css is authored. tokens.json, tokens.js, tokens.d.ts and the Tailwind bridge are generated by the build, and CI runs a diff afterwards — so a hand-edit or a forgotten regeneration fails rather than drifting quietly.

Watch outAdding a token requires a matching Tailwind emit in the same commit. The build refuses otherwise, because a token no utility can reach is a token half the codebase cannot use.

Dark mode

The tokens flip under [data-theme="dark"]. There is no second stylesheet and no media query of your own to write: use the semantic names and both themes are correct.
