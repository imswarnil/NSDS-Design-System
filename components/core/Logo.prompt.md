The responsive wordmark lockup — icon + name, or `compact` icon-only for narrow navbars/favicon-sized slots. Uses only the source repo's real favicon asset; no invented pictorial mark.

```jsx
<Logo />
<Logo compact size={20} />
<Logo light text="Namaste Salesforce" />
```
Swap to `compact` at your own narrow-viewport breakpoint (mobile navbar, collapsed sidebar).
