A horizontal step progress bar — mono-numbered nodes joined by a hairline that fills brand-blue as steps complete. For course/training players and any multi-step flow (checkout, onboarding). Distinct from `CurriculumList` (a lesson rail) and `RoadmapCard` (a roadmap stop).

```jsx
<TimelineStepper steps={["Watch", "Read", "Quiz", "Done"]} activeIndex={1} />
```
