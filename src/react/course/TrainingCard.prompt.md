A training-section grid card for a `/training/` overview page — icon tile, mono section number, lesson/duration meta, and an optional thin progress bar. Distinct from `RoadmapCard`, which is the spine-connected version shown on the roadmap page itself.

```jsx
<TrainingCard n={2} title="Org Setup" desc="Editions, licenses, baseline settings." icon="ph-gear-six" lessons={5} duration="55m" progress={40} />
```
